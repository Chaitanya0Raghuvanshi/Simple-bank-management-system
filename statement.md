# Simple Bank Management System

## 1. Problem Statement

Create a simple Python program that allows a user to perform basic banking operations.

The program should ask the user for a PIN before giving access to the banking menu.
After logging in, the user should be able to check their balance, deposit money, withdraw money,
view transaction history, and check the total number of transactions.

## 2. Scope of the Project

This project is made for basic banking operations.

The program can:

* Check the account balance
* Deposit money
* Withdraw money
* Store transaction details
* Display transaction history
* Count successful transactions
* Check the PIN before login

This project is a basic learning project and does not connect to a real bank account or real banking system.

## 3. Target Users

This project is mainly useful for:

* Students learning Python
* Beginners practicing programming
* Users who want to understand basic banking operations
* Students working on Python mini projects

## 4. High-Level Features

The main features of the project are:

1. **PIN Login**
   The user must enter the correct PIN to access the program.

2. **Check Balance**
   The user can see the current account balance.

3. **Deposit Money**
   The user can add money to the account.

4. **Withdraw Money**
   The user can withdraw money if enough balance is available.

5. **Transaction History**
   The program stores and displays deposit and withdrawal transactions.

6. **Transaction Count**
   The program displays the total number of successful transactions.

7. **Exit**
   The user can exit the program using the exit option.

## 5. Working of the Program

The program starts with a balance of 5000.

First, the user enters the PIN. If the PIN is correct, the main menu is displayed.

The user can then select an option from the menu.

For deposits and withdrawals, the program checks whether the entered amount is valid.
In case of insufficient balance, the withdrawal is not performed.

## 6. Input

The program takes:

* PIN
* Menu choice
* Deposit amount
* Withdrawal amount

## 7. Output

The program displays:

* Current balance
* Deposit confirmation
* Withdrawal confirmation
* Transaction history
* Total transaction count
* Error messages for invalid operations
